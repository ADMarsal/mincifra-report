# Отчёт по стажёрам для Минцифры

## Какую рутину автоматизирует проект

Каждый отчётный период я вручную сверяю общую таблицу стажёров компании со
списком Минцифры: подходит ли вуз, подходит ли направление обучения, сколько
часов отработал студент. После этого собираю сводку по вузам и считаю суммы.
Вручную это занимает несколько часов, а таблица большая, поэтому легко ошибиться.

Программа читает общую таблицу Excel, проверяет каждого студента по правилам
и собирает итоговый отчёт в Excel.

## План работы

- [x] **Часть 1.** Чтение общей таблицы: поиск строки заголовков, нужных столбцов, список студентов
- [x] **Часть 2.** Короткие названия вузов (словарь «полное название → короткое»)
- [x] **Часть 3.** Проверка по списку Минцифры: вуз и направление
- [x] **Часть 4.** Статусы: «Подходит» / «Не подходит» / «На проверку»
- [x] **Часть 5.** Итоговый отчёт Excel: сводная по вузам, часы, деньги

## Как запустить

Нужен Python 3.10 или новее.

```bash
# 1. Один раз: создать окружение и установить библиотеку
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Запуск на файле-примере
python3 main.py

# 3. Запуск на своём файле
python3 main.py путь/к/таблице.xlsx
```

Пример вывода:

```
Файл: data/example_students.xlsx
Прочитано студентов: 25
Всего часов: 17306

Студентов по вузам:
  ВШЭ: 3
  ИТМО: 8
  ...

Проверка по списку Минцифры:
  Вуз есть в списке: 22 из 25
  Вуз и направление подходят: 6 из 25

Статусы:
  Подходит: 6
  На проверку: 3
  Не подходит: 16

Отчёт сохранён: output/report.xlsx
```

## Что в отчёте `output/report.xlsx`

| Лист | Что на нём |
|---|---|
| Студенты | Все студенты: вуз, направление, часы, статус |
| Сводная по вузам | Только подходящие студенты: сколько человек, часы и деньги по каждому вузу, строка «Итого» |
| На проверку | Студенты, которых нужно проверить вручную |

Статусы:
- **Подходит**: вуз и направление есть в списке Минцифры;
- **На проверку**: вуза нет в словаре или направление не заполнено, программа не может решить сама;
- **Не подходит**: всё заполнено, но вуза или направления нет в списке.

Деньги = часы × ставка `MONEY_PER_HOUR` из `config.py`.

## Структура

```
main.py       запуск: берёт путь к файлу, обрабатывает ошибки, печатает итог
reader.py     чтение Excel: строка заголовков, нужные столбцы, список студентов
universities.py короткие названия вузов по словарю data/universities.csv
mincifra.py   проверка по списку Минцифры data/mincifra_list.csv
statuses.py   статусы: Подходит / На проверку / Не подходит
report.py     итоговый отчёт Excel output/report.xlsx
config.py     настройки: имена столбцов, файлы, статусы, ставка за час
data/         пример таблицы с выдуманными данными, словарь вузов, пример списка Минцифры
```

## Какие ошибки обрабатываются

| Ситуация | Что увидит пользователь |
|---|---|
| Файла нет | `Ошибка: файл не найден: ...` |
| Файл не Excel или с другим расширением | `Ошибка: файл не похож на Excel (.xlsx): ...` |
| Файл открыт или нет доступа | `Ошибка: нет доступа к файлу ...` |
| В таблице нет заголовка «Сотрудник» или нужного столбца | `Ошибка в структуре файла: ...` |
| Нет словаря вузов `data/universities.csv` | `Ошибка: файл не найден: data/universities.csv` |
| Нет списка Минцифры `data/mincifra_list.csv` | `Ошибка: файл не найден: data/mincifra_list.csv` |
| Отчёт открыт в Excel и не сохраняется | `Ошибка: не удалось сохранить отчёт - закройте ...` |
| В словаре или списке строка без «;» | `Ошибка в структуре файла: data/universities.csv, строка 8: ...` |

## Словарь вузов

`data/universities.csv`: в каждой строке ключевые слова и короткое название через `;`.
Если ключевые слова встречаются в полном названии вуза из таблицы, программа
берёт короткое название. Новый вуз добавляется одной строкой, код менять не нужно.

## Список Минцифры

`data/mincifra_list.csv`: в каждой строке вуз (короткое название, как в словаре)
и направление через `;`. Студент подходит, если его направление есть в списке
именно для его вуза. Направление может быть записано с кодом
(«09.03.03 Прикладная информатика»), программа всё равно его найдёт.
В репозитории лежит пример. Настоящий список кладётся на его место.

## Про данные

В репозитории лежит только пример с выдуманными студентами
(`data/example_students.xlsx`). Настоящая таблица содержит персональные
данные, поэтому её кладут в `data/private/`. Эта папка указана в `.gitignore`
и на GitHub не попадает.
