# Отчёт по стажёрам для Минцифры

## Какую рутину автоматизирует проект

Каждый отчётный период я вручную сверяю общую таблицу стажёров компании со
списком Минцифры: подходит ли вуз, подходит ли направление обучения, сколько
часов отработал студент. После этого собираю сводку по вузам и считаю суммы.
Вручную это занимает несколько часов, а таблица большая, поэтому легко ошибиться.

Программа читает общую таблицу Excel, проверяет каждого студента по правилам
и собирает итоговый отчёт в Excel.

## План работы

- [x] **Часть 1.** Чтение общей таблицы: поиск строки заголовков, нужных столбцов, список студентов
- [ ] **Часть 2.** Короткие названия вузов (словарь «полное название → короткое»)
- [ ] **Часть 3.** Проверка по списку Минцифры: вуз и направление
- [ ] **Часть 4.** Статусы: «Подходит» / «Не подходит» / «На проверку»
- [ ] **Часть 5.** Итоговый отчёт Excel: сводная по вузам, часы, деньги

## Как запустить

Нужен Python 3.10 или новее.

```bash
# 1. Один раз: создать окружение и установить библиотеку
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. Запуск на файле-примере
python3 main.py

# 3. Запуск на своём файле
python3 main.py путь/к/таблице.xlsx
```

Пример вывода:

```
Файл: data/example_students.xlsx
Прочитано студентов: 25
Всего часов: 17306
```

## Структура

```
main.py       запуск: берёт путь к файлу, обрабатывает ошибки, печатает итог
reader.py     чтение Excel: строка заголовков, нужные столбцы, список студентов
config.py     настройки: имена столбцов, файл по умолчанию
data/         пример таблицы с выдуманными данными
```

## Какие ошибки обрабатываются

| Ситуация | Что увидит пользователь |
|---|---|
| Файла нет | `Ошибка: файл не найден: ...` |
| Файл не Excel или с другим расширением | `Ошибка: файл не похож на Excel (.xlsx): ...` |
| Файл открыт или нет доступа | `Ошибка: нет доступа к файлу ...` |
| В таблице нет заголовка «Сотрудник» или нужного столбца | `Ошибка в структуре таблицы: ...` |

## Про данные

В репозитории лежит только пример с выдуманными студентами
(`data/example_students.xlsx`). Настоящая таблица содержит персональные
данные, поэтому её кладут в `data/private/`. Эта папка указана в `.gitignore`
и на GitHub не попадает.
